A [make.fun](https://make.fun/c/u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018) entry for the **Two Days of Quiet Dread** bounty: a program that writes one single-line code review comment approving a pull request with quiet existential dread.

## Entry

> LGTM. Clean diff, green tests, and the quiet certainty this code will outlive us both.

## Run

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
